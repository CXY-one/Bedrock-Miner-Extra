# Bedrock Miner Extra 2.5.3

## 更新内容

- 适配 Minecraft 26.3，并保留 1.19.4、1.20.x、1.21.x、26.1、26.1.2、26.2 等版本构建。
- 修复白名单命令的完整方块 ID 解析：简写和带 `minecraft:` 前缀的 ID 都可以添加、删除，Tab 补全结果也能正常使用。
- 自动模式新增快捷键，可在 malilib 配置界面中设置；快捷键切换时显示物品栏上方提示，设置会保存并在重启后保留。`/bedrockMinerExtra auto` 仍可直接切换自动模式。
- 修复立式告示牌与墙面告示牌的白名单识别，支持手动破坏。自动模式在空间受限的布局中仍可能提示空间不足，此时可以使用手动模式。
- 新增粘性活塞支持开关，默认关闭；开启后优先使用普通活塞，只有没有普通活塞时才使用粘性活塞。
- 自动挖掘预热时间调整为约 0.2 秒，之后保持使用最快的可用工具；只有达到瞬间破坏速度时才走瞬挖收尾。

## 构建产物

本目录包含 11 个支持版本的客户端 JAR：1.19.4、1.20.1、1.20.5、1.20.6、1.21、1.21.1、1.21.11、26.1、26.1.2、26.2、26.3。
